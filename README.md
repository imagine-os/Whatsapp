# Threadline

Turn a WhatsApp project chat into threads, decisions, open asks and risks.

- Import a chat export (WhatsApp > chat > Export chat > Without media), drop the .zip or .txt.
- Everything is parsed in the browser and stored only on that device.
- Live sync needs the WhatsApp Business Platform (business number, Meta app, webhook server); not wired up yet.
- Claude analysis works when the page is opened as a claude.ai artifact; on this public site the on-device keyword analysis runs.

Site: https://imagine-os.github.io/Whatsapp/
